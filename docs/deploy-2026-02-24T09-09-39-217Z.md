# Documento Técnico - Deploy

1. **Resumen Ejecutivo**
   El cambio en el archivo `server.js` implica una actualización en cómo se sirven los archivos estáticos en el servidor Express. Este ajuste se centra en servir archivos HTML por defecto cuando no se especifique una extensión durante la navegación en el frontend. La modificación responde a un issue donde se demandaba mejorar la accesibilidad de las rutas sin especificar extensiones, mejorando la usabilidad y consistencia en la navegación del frontend.

2. **Cambios Backend (express)**
   Se ha modificado la configuración del middleware `express.static` en el archivo `server.js` para que, además de servir archivos estáticos desde la carpeta `public`, considere archivos con la extensión `.html` automáticamente cuando las rutas no incluyen una extensión específica. Este cambio afecta la manera en que se resuelven y sirven las rutas en el servidor:

   ```diff
   - app.use(express.static(path.join(__dirname, 'public')));
   + app.use(express.static(path.join(__dirname, 'public'), { extensions: ['html'] }));
   ```

3. **Cambios Frontend (carpeta /public)**
   No se han realizado cambios directos en los archivos HTML, JS, o CSS del lado del cliente en la carpeta `/public`. Sin embargo, la forma en que estos se acceden ha sido optimizada gracias a las modificaciones en el backend.

4. **Impacto Técnico**
   Los cambios permitirán una experiencia de usuario más fluida, ya que los usuarios pueden acceder a rutas sin tener que especificar explícitamente la extensión `.html`. Esto no solo reduce el riesgo de errores por URLs mal estructurados, sino que también mejora el SEO al garantizar rutas más limpias.

5. **Riesgos**
   - La configuración alterada podría llevar a conflictos si existen múltiples archivos con el mismo nombre pero diferentes extensiones en el directorio de archivos estáticos.
   - Si el servidor no está correctamente configurado para manejar otras extensiones por defecto, podría provocar errores 404 cuando se espere que otras extensiones además de `.html` se sirvan automáticamente.

6. **Consideraciones de Deploy**
   - Asegurarse de que el directorio `/public` no contenga archivos potencialmente conflictivos (mismo nombre, distinta extensión).
   - Verificar que la aplicación esté correctamente configurada para manejar otros tipos de archivos que puedan necesitar extensión por defecto si no hay extensiones especificadas.
